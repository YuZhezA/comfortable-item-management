# 0.1.4 单击与拖拽实机验收

## 输入规则

工作台和生存物品栏共用整组拖拽手势。从普通存储槽按下 `Shift` + 左键时先记录起点。在原槽松开触发一次原版 `QUICK_MOVE`。按住离开起点时，按原来的拖拽规则处理起点和进入的槽，此后每次进入一个槽都能继续移动。

用 Mojang 映射下的 Minecraft 1.20.1、1.21.1、1.21.11 和 26.3 JAR 核对了 `CraftingMenu.quickMoveStack`。工作台先尝试 3×3 合成输入，放不进去时再尝试背包和快捷栏互转。个人物品栏沿用 `InventoryMenu.quickMoveStack` 的原版装备判定和空槽限制。加载 Item Scroller 或 Rock’n Roller 时，共有 `Shift` + 左键手势沿用上游规则。

## 游戏内验证

`tools/play-drag-regression.py` 在相同版本的原版专用服务端上读取物品与槽位，并保存真实客户端截图。工作台部分先从快捷栏移动 4 个石头，再从背包移动 5 个泥土，然后从两个合成格逐一取回，检查服务器最终认可的种类、数量和位置。另验证合成格全满时的原版回退，并在同槽内挪动鼠标验证释放前没有提前移动。

生存物品栏分别单击背包中的铁胸甲和快捷栏中的铁头盔。检查装备槽，再单击金胸甲，验证已装备的铁胸甲保持原位且金胸甲留在玩家物品栏。原有拖拽检查覆盖工作台、背包、箱子、潜影盒和创造物品栏个人背包页，包括按住左键来回转移与满槽保护。复验方法见[实机验收记录](playtest.md)。
