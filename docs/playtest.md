## 覆盖与证据

- 核心流程通过副屏真实键鼠输入操作箱子、背包和世界。服务端在每步读取库存、箱子内容和适用的副手字段。截图记录容器打开、操作后界面及世界最终画面。
- 扩展流程使用独立的 JSON 启用严格预损替换，覆盖耐久 9/10 点、备用件排序及完整物品数据比较。通过原版按键绑定界面测试改键后，直接读取 JSON，再在原版服务端用新键触发整理。
- [共存矩阵](coexistence.md)记录上游构件来源与实测结果。只有共存实例包含上游模组和其依赖。
- 每个安装产物与测试实例的 SHA-256 逐一核对。`launch.json` 记录运行配置与实际装入的 JAR 哈希。`playtest.json` 记录输入、预期及原版认可的状态。`manifest.json` 汇总构建、客户端、用例和状态。
